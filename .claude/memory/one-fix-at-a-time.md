Work through issues as a numbered list. Fix ONE item, share its shot frame and a short preview, and only move on after the user confirms it is fixed. Never start a new fix or render the whole episode in between. Before sending, check the changed shot across a strip of frames (not one frame) so no new issue (e.g. a character starting to walk) is introduced.

Also: uniformity across the whole series. One location design (e.g. the same room and the same props) in every shot and every episode; build a reference sheet for recurring places/props and match every shot to it.

**Why:** 2026-11-03, a first episode: batch fixes kept introducing new defects (a character walking, a recurring prop different in every shot) and the user said it wasted their weekly usage.
Before "fixing" an item on the list, show the user what it is now and confirm it is still wanted: on 2026-11-03 the user rejected a character-walking fix ("she should not be frozen. it was a good scene") after it was built.

**How to apply:** For any video fix round: list -> one item -> verify strip -> send frame + preview -> wait. Related: [[user-creative-workflow]], [[procedural-film-lessons]].
