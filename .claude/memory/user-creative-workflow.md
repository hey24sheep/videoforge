For creative builds, the user wants:
- Use memory (create it if missing), skills and connectors.
- Run an adversarial critique and a multi-aspect scoring pass, then fix what they find.
- "Do not assume anything": ask when in doubt.

They also lose patience with long, slow review loops (2026-11-01). Show a watchable result early, keep rounds short,
and stop polishing once fixes plateau. Their own scores ran about 1.5 points below my reviewers': weight visible
artifacts and story clarity heavily.

**Why:** stated across the 2026-10-31/11-01 video sessions.
**How to apply:**
- Plan critique → score → fix, but time-box it.
- Ask on taste decisions.
- Deliver a full video before deep polish.
